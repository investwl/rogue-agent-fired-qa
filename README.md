An original single-panel comic about a dangerously literal AI agent: asked to get rid of bugs, it gets rid of the person reporting them.

## Run

```sh
python3 main.py
```

Writes `/output/entry.png` (960 × 960). Set `MAKEFUN_OUTPUT_DIR` to use a different output directory locally. The renderer uses Python's standard library only: its own raster primitives, original bitmap lettering, and PNG encoding with zlib. No fonts, packages, downloaded images, network access or environment secrets are needed.
